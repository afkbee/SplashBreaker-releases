# SplashBreaker releases

Windows installers for SplashBreaker. This repo only holds releases; it is also the app's update feed.

## Install

1. Open the [latest release](https://github.com/afkbee/SplashBreaker-releases/releases/latest).
2. Download `SplashBreaker-Setup-<version>.exe` and run it.
3. The app isn't code-signed yet: if Chrome warns, choose **Keep**; if Windows shows "Windows protected your PC", choose **More info → Run anyway**.

The installed app updates itself. The `-portable.exe` runs without installing but doesn't update itself.
